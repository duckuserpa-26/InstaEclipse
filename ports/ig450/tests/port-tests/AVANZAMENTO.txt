LIMITI DEI TEST
La conversione dex2jar 2.4 non produce gli stack-map frame richiesti dalla
versione JVM iniziale del JAR: il primo avvio ha quindi restituito VerifyError.
Per il test JVM e' stato usato il class-version-switch di dex2jar con target
Java 6 (class version 50), mantenendo java -Xverify:all attivo. Il DEX Android
non e' stato alterato da questa conversione. Non e' una verifica ART.
Un primo controllo del campo $t e' fallito per un errore nella regex del
verificatore, corretto riconoscendo anche i nomi che iniziano con $.
JADX produce ancora artefatti Java non compilabili in alcuni file: lo Smali
rimane il sorgente canonico di questa ricostruzione.
L'API di Vector e' verificata nel sorgente, non sul telefono dell'utente.
